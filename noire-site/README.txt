NOIRE site
1) Files: index.html (structure), style.css (design), script.js (logic). Open the folder in VS Code (Live Server extension to preview).
2) Edit the first lines of script.js: WA (WhatsApp number, e.g. 2010xxxxxxxx), SHIP, DAYS, and the P list (products and prices).
3) Put new photos in images/ and register them in IMG.
4) Upload everything to a GitHub repo, then Settings > Pages > Deploy from branch (main, root).
